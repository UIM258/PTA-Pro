# PTA 收藏夹 AI Prompt / Skill

`persist: true` 的 Skill 结果可以写入题目的“可改成参考答案与解析”。

`persist: false` 的 Skill 只在当前 AI 面板中显示，默认不写入本地题目档案。

| Skill | 是否持久保存 | 用途 |
|---|---|---|
| analyze-problem | 是 | 简要解析题意 |
| reference-solution | 是 | 生成参考答案和参考实现 |
| knowledge-points | 是 | 提取知识点和复习建议 |
| review-my-code | 否 | 检查用户当前代码 |
| hint-progression | 否 | 渐进式提示 |
| debug-compile-error | 否 | 解释编译错误 |
| generate-edge-cases | 否 | 生成边界测试思路 |
