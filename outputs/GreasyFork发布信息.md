## 附加信息

PTA-Pro 是一个面向 PTA（拼题A）的收藏夹脚本。它可以帮助你收藏题目、按题目集和题型整理收藏、保存本地快照，并在计时结束后继续查看自己保存过的内容和作答。

主要功能：

- 题目标题前星标收藏，左键收藏/取消，右键管理。
- 按题目集自动归档，并支持自定义收藏夹。
- 支持收藏夹和收藏题目的拖动排序、搜索、分页和批量管理。
- 保存原题页面快照，支持编辑答案和代码。
- 保存 PTA 可见提交记录、判题结果和测试点信息。
- 支持 OpenAI 兼容 API 的 AI 学习助手。
- 支持 Markdown、JSON 导出与导入。
- 支持自定义快捷键和夜间模式。

隐私说明：

- 收藏、快照和设置默认仅保存在当前浏览器本地。
- AI API Key 单独保存在本地，不会进入 JSON 或 Markdown 导出。
- 使用 AI 功能时，仅向用户配置的 API 服务发送必要题目上下文。

合规说明：

本脚本用于个人学习、复习和资料整理。请遵守所在学校、PTA 及相关课程的使用规范，不要使用脚本绕过考试限制、访问隐藏测试点或自动提交答案。
