# PTA 收藏夹用户脚本

## 安装

1. 在 Chrome 或 Edge 中安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，新建脚本。
3. 用 `pta-favorites.user.js` 的全部内容替换默认模板并保存。
4. 打开任意 `*.pintia.cn` 页面，右下角会出现“PTA 收藏夹”按钮。

## 收藏操作

- 星标统一放在题号/标题前面。
- 左键点击星标收藏。
- 再次左键点击同一星标取消收藏，并删除对应本地快照。
- 右键点击星标，无论是否已收藏，都会在居中弹窗中打开详细收藏页面。
- 详细收藏页面可以直接“+ 新建收藏夹”。
- 取消全部收藏夹等同于取消收藏。
- 右下角“PTA 收藏夹”按钮不显示数字。

## 收藏夹与批量管理

- 默认收藏夹、自定义收藏夹和“题目集 / 题型”归档均已支持。
- 题目集目录支持折叠和展开。
- 收藏列表右上角有“批量管理”按钮。
- 点击“批量管理”后才会显示：
  - 题目前的选择框
  - 全选
  - 已选数量
  - 删除
  - 复制到收藏夹
  - 移动到收藏夹
  - 未做 / 在做 / 已做
  - 取消批量管理

## 详细收藏页面

- 可编辑标题、题号、题型、题目集、学习状态、标签和备注。
- 可编辑参考答案、答案解析和答案状态。
- 不再显示编辑页“我的作答”代码。
- 不再显示“我的答案”编辑框。
- 不再显示整块“PTA 判题记录”。

## 快照

- 快照保存原题 HTML、PTA 样式表引用和内联 CSS。
- 查看快照时先显示题目，再显示“我的作答”和“评测详情”。
- 选择题只显示简洁答案，例如 `C.108`。
- 函数题和编程题使用浅色代码查看器：
  - `[ C ] / [ C++ ]` 语言栏
  - 行号
  - 基础语法着色
  - 复制按钮
  - 原代码缩进和换行
- PTA 测试点、编译输出收纳在“PTA 评测详情”折叠区域。
- 快照中不会保留无法工作的“格式 / 复制内容 / 全屏”等 PTA 控件。
- 旧快照查看时也会自动移除这些失效按钮。

## 编程题和函数题的判定方式

脚本不会在本地模拟编译或代替 PTA 判题。正确性完全以 PTA 返回结果为准：

- `答案正确 / AC`
- 部分通过
- `WA / TLE / MLE / RE / CE` 等状态
- 总分和满分
- 可见测试点及每个测试点的结果
- 编译器输出
- 提交代码和真实提交时间

打开提交结果弹窗时，脚本会自动保存这些信息。未提交前只能保存编辑器中的代码草稿，不能判断正确性。

## 数据保存位置

- 收藏元数据和收藏夹：Tampermonkey 存储。
- 题目快照和大文本：优先使用浏览器 IndexedDB，失败时回退到 Tampermonkey 存储。
- 数据默认只保存在本机，不上传到第三方服务。
- 不同浏览器或不同浏览器配置之间目前需要手动导出/导入 JSON。

## 使用边界

- 只保存当前账号有权查看的内容。
- 不绕过题目的时间限制、权限限制或隐藏测试点。
- 不自动提交代码。
- 只有 PTA 页面实际展示答案时，脚本才能保存官方答案。
- 如果题目集只公布总分而不公布题目答案，脚本会保留成绩状态，并提供手动补充答案的位置。
- PTA 页面结构变化后，可能需要更新识别规则。


## AI 功能设计

AI 功能目前处于设计阶段，设计文档：

- `outputs/AI功能设计.md`
- `outputs/ai-prompts/README.md`

设计原则：

- 题目解析、参考答案和知识点可以保存，并标注 AI 来源。
- 用户代码检查、提示、编译错误解释等默认只临时生成，不写入本地收藏数据。
- 支持用户自定义 OpenAI 兼容 API。
- 不自动提交代码，不使用隐藏测试点。
