# PTA 收藏夹 AI 交互设计

## 1. AI 入口

AI 助手提供三个正式入口。

### 1.1 收藏卡片入口

每张收藏卡片底部：

```text
[管理] [本地快照] [更新快照] [AI]
```

点击后打开 AI 助手面板。

默认上下文：

- 当前收藏题目的最新快照
- 用户本地编辑后的答案或代码
- 如果没有本地编辑，则使用 PTA 最近提交
- 如果存在 PTA 评测结果，一并发送

### 1.2 本地快照页面入口

本地快照弹窗底部：

```text
[上一题] [下一题] [单栏/并排] [AI 助手] [打开原题] [刷新快照]
```

点击 AI 助手后，不关闭当前快照。

单栏模式：

- AI 面板从右侧覆盖显示。
- 快照仍然保持在左侧。

并排模式：

- 右侧已有“我的作答、评测详情、参考答案”时，切换为标签页：
  - 我的内容
  - PTA 评测
  - AI 助手

这样不会变成三栏，避免页面过窄。

### 1.3 管理页面入口

“管理 -> 可改成参考答案与解析”中增加：

```text
[AI 生成解析] [AI 提取知识点]
```

生成结果直接进入 AI 解析区块，并显示来源标记：

```text
[AI 生成]
模型：xxx
生成时间：xxx
基于快照：xxxx
```

## 2. 快照页面的上下文优先级

AI 助手在快照页面打开时，上下文按以下优先级选择。

### 题目内容

1. 当前快照 Markdown
2. 当前快照 HTML 的纯文本版本
3. 当前题目元数据

### 用户答案

1. `snapshot.localAnswers`
2. PTA 原始答案
3. 用户笔记中的答案

### 用户代码

1. `snapshot.localCode`
2. PTA 最近提交代码
3. 编辑器代码草稿

### PTA 评测信息

- 编译器和判题限制
- 最近提交状态
- 分数
- 可见测试点
- 编译器输出

## 3. AI 面板结构

```text
AI 助手
题目：7-1 顺序表区间元素删除

上下文：
[✓] 题目内容
[✓] 我的作答/代码
[✓] PTA 可见评测信息
[ ] 参考答案与解析

[题目资料] [我的内容]

题目资料：
[简要解析] [参考答案] [知识点] [复杂度] [边界情况]

我的内容：
[检查答案] [检查代码] [编译错误] [渐进提示] [生成测试]

[输入自定义问题]
```

## 4. 持久化规则

### 自动保存到题目的内容

- 简要解析
- 参考答案
- 参考代码
- 知识点
- 复杂度
- 边界情况

用户点击生成按钮即视为同意保存。

数据写入：

```json
{
  "answer": {
    "ai": {
      "analysis": "",
      "answer": "",
      "referenceCode": "",
      "knowledgePoints": [],
      "complexity": {
        "time": "",
        "space": ""
      },
      "model": "",
      "skillId": "",
      "skillVersion": "",
      "generatedAt": 0,
      "basedOnSnapshotHash": ""
    }
  }
}
```

### 不保存的内容

- 检查我的答案
- 检查我的代码
- 编译错误对话
- 渐进提示
- 测试用例对话
- 多轮追问

这些内容保存在当前 AI 面板的内存会话中，面板关闭即清除。

## 5. 快照页面交互状态

```text
快照打开
  -> 点击 AI 助手
  -> 选择“题目资料”或“我的内容”
  -> 选择具体 Skill
  -> 显示请求预览
  -> 用户确认发送
  -> 显示 AI 输出
  -> 持久化 Skill：写入题目档案
  -> 临时 Skill：只保留在当前面板
```

## 6. 请求预览

发送前显示：

```text
即将发送：
- 题目正文：约 1200 字
- 当前本地代码：约 800 字
- PTA 可见评测结果：3 个测试点
- API 地址：xxx
- 模型：xxx
```

用户可以取消勾选不想发送的内容。

## 7. 快照编辑与 AI 结果的优先级

如果用户已经本地修改答案：

```text
[本地修改]
我的作答：C.O(N),O(1)
```

AI 默认分析本地版本，不分析 PTA 原始版本。

如果用户希望分析原始版本，可以选择：

```text
分析版本：
- 当前本地快照
- PTA 原始数据
```

## 8. AI 结果操作

每条持久化结果支持：

- 复制
- 重新生成
- 编辑
- 删除
- 标记为“已复核”
- 合并到“参考答案与解析”

临时结果支持：

- 复制
- 继续追问
- 手动保存为备注
- 手动合并到“参考答案与解析”

不会自动升级成持久内容。

## 9. 快捷键

新增可自定义快捷键：

```text
Alt + Shift + A：打开/关闭 AI 助手
Alt + Shift + R：重新生成当前 AI 内容
```

快捷键只在非编辑状态生效。

## 10. 快照页面 UI 规模

建议 AI 面板宽度：

```text
单栏模式：420px，右侧覆盖
并排模式：复用右栏，使用标签页
窄屏模式：全宽弹窗
```

## 11. 失败状态

- 未配置 API：显示配置按钮
- API Key 失效：保留输入内容
- 请求超时：允许重试
- 返回空内容：提示模型未返回有效结果
- 上下文过长：允许只发送题目正文
- 用户取消：不产生本地记录

### 我的内容
